# Balerion

The dragon that guards your digital workspace.

```bash
npm install -g balerion-cli
balerion
```

Balerion is an agentic CLI that breathes fire into your terminal — reading, reasoning, and rewriting across your Obsidian vaults, codebases, and creative projects. Not a chatbot that waits. A dragon that acts.

It reads thousands of interconnected notes, edits files, runs commands, searches codebases, and fetches knowledge from the web. All without leaving your terminal. Think of it as Claude Code meets Obsidian — a creative partner for developers, writers, and thinkers who want an AI that actually does things.

Free and paid models via OpenRouter. No vendor lock-in. Just a dragon in your shell.
